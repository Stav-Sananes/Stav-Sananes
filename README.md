### 🛠️ Things I've built

**[Receptra](https://github.com/Stav-Sananes/Receptera): a Hebrew voice co-pilot for small businesses**
Small businesses in Israel answer a lot of phone calls in Hebrew, and most AI tools either don't speak Hebrew well or send every call to the cloud. Receptra listens to the live call and suggests grounded replies in under two seconds, running entirely on the agent's Mac. No cloud, no API key.

**[llm-gateway](https://github.com/Stav-Sananes/llm-gateway): one front door for LLMs and MCP tools**
Once a team uses several models and tool servers, nobody knows who called what or what it cost. The gateway puts per-tenant keys, rate limits, token budgets, a policy check on every tool call and a tamper-evident audit log in front of all of them, with every hop traced.

**[finally-good-ui](https://github.com/Stav-Sananes/FinallyGoodUI): AI-built UIs that don't look AI-built**
AI design tools hand the model presets and style catalogs, which is why their output all looks the same. This Claude Code plugin gives the model judgment instead: design principles, explicit trade-offs, and a check of the rendered screen against those principles. It designs whole apps, with every empty, loading and error state.

**[Pastie](https://github.com/Stav-Sananes/Pastie): a clipboard manager for macOS**
macOS keeps exactly one thing on the clipboard. Pastie lives in the menu bar, remembers what you copied, lets you search it, and pastes any entry back with a keystroke.

**[cs16-deathmatch-server](https://github.com/Stav-Sananes/learning-projects/tree/main/powershell/cs16-deathmatch-server): Counter-Strike 1.6 in one double-click**
Setting up an old CS 1.6 server means hours of HLDS, Metamod, AMX Mod X and bot configs. One script does all of it, with a menu for install, game mode and diagnostics.

### 🧭 How I work

- **Architecture first.** I build on solid engineering principles: clear boundaries, code that is easy to change, a design that fits the problem rather than the framework.
- **AI agents as teammates.** I work with AI coding agents every day, and I give them the same standards I hold myself to: my own skills, agents and rules for design, testing and reliability.
- **Learning from mistakes on purpose.** I keep a log of every mistake: what happened, why, and how to prevent it. When the same one shows up three times, it becomes a rule.
- **Always learning.** Coding challenges, deep dives into how tools work under the hood, and side projects just to understand something new.
