## Hi, I'm Stav 👋

I'm a full-stack developer. I build AI products and developer tools, and Hebrew-first software for the Israeli market.

### What I'm building

- **AI tooling.** [llm-gateway](https://github.com/Stav-Sananes/llm-gateway): a self-hostable gateway that adds per-tenant keys, budgets, policy checks and an audit log in front of LLMs and MCP servers. [Receptra](https://github.com/Stav-Sananes/Receptera): a Hebrew voice co-pilot that suggests replies during a live phone call, fully on-device.
- **Tools for working with Claude Code.** [finally-good-ui](https://github.com/Stav-Sananes/FinallyGoodUI) designs complete app UIs from design principles instead of presets.
- **Hebrew-first products.** Event management, a legal small-claims assistant, workflow software for insurance appraisers, and shared grocery lists with price comparison.
- **Small tools.** [Pastie](https://github.com/Stav-Sananes/Pastie), a clipboard manager for macOS.

### How I work

- I work with AI agents every day, and I give them rules. My Claude Code setup turns engineering books (Clean Code, Clean Architecture, Refactoring, Release It!, DDD, TDD) into skills the agent has to apply.
- Tests first. Small, readable functions. Clear boundaries between the domain and the framework.
- I log every mistake, why it happened and how to prevent it. When the same one shows up three times, it becomes a hard rule.
